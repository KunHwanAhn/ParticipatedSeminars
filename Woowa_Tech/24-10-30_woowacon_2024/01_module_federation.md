### Module Federation (MF)
- 각각 독립적으로 배포 가능한 Module을 브라우저 런타임에서 동적으로 로드하고 통합하여 하나의 프로덕트로서 동작하게 하는 기술
- Micro Front Architecture를 구축하는 방법 중 하나

#### Terms
- Module - 재사용할 수 있는 MF의 최소의 단위
- Host - Remote를 불러와서 사용하는 재사용 가능한 Module
- Remote - Host에서 불러와서 사용하는 재사용가능한 Module
- Host <--Consume-- Remote
- Sharing Dependency - 모듈간 공통으로 사용되어 공유 ㅓㄹ정을 한 Dependency
  - React, React Dom 등
- Remote Entry - 실행 전 preload하는 것

#### 단점
- 러닝커브
  - 내부 동작 매커니즘 학습 필요
  - 모듈 단위의 새로운 협업 체계 전파 필요
  - 커뮤니케이션 비용 함께 증가
- 불확실성
  - 대규모 적용 사료 부족
  - UX개선지속적인 연구 필요

#### 장점
- 유연한 합병 & 관리
- 커뮤니티의 성장
