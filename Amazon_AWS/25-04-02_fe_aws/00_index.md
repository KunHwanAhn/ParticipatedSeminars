## Why Cloud?
- 하늘과 같은 무한한 자원
- 자원을 탄력적으로 분배 가능

### Cloud vs On Premise

#### Cloud Service
- 사용한만큼 (On Demand)
- 덜 안전하지만 보안 대체 가능
- 탄력적인 (Elastic)

#### On Premise
- 초기 구축 비용 높음
- 안전하지만 보안 구축 필요
- 하드웨어 구매 및 설치 시간 필요

## 프론트엔드 배포 트렌드
- 정적인
  - 리액트, 스벨트, 뷰 => CSR & SSG
- 동적인
  - Next.js => SSR

### 웹 배포가 복잡해진 이유는?
- 유저의 경험이 늘어날수록 웹 복잡도가 올라감
- 복잡한 웹
  - 웹에서 게임하는 시대. e.g. 포켓로그 with WASM

### 정적 배포
- AWS S3 (웹서버 & 저장소) & CloudFront (CDN)

### 동적 배포
- AWS EC2 or AWS Fargate
- Docker, Image Registry(ECR, Docker Hub 등)

### Scale Up
- 수직적 확장
- 서버의 양적 크기 증가
- 스케일업은 자원에 한계가 있기 마련

- 수평적 확장
- 서버의 수적 증가

> Scale Out이 비용적인 측면에서 봤을 때도 선형적으로 증가하기에 비용 증가율이 낮아서 좋음
