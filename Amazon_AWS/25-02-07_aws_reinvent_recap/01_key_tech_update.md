## Amazon.com 사례
- Customer Service
  - 고객 응대 서비스(챗봇 서비스)
- Sizing
  - 제품을 선택하는 구매자의 사이즈를 맞춤혐으로 제공
  - 고객 데이터 뿐만 아니라 카탈로그 데이터를 기반으로 분석하여 추천
- Details page creation for sellers
  - 입점해있는 고객사들이 많은 경우, 이걸 정리하는 것만해도 일이 어마어마함
  - 상품을 입력하면 자동으로 설명문을 만들어주는 기능이라던지, 효율화할 수 있는 부분이 있음
- Rufus
  - 쇼핑 어시스턴트 서비스
  - 아마존닷컴 진입 시 Rufus를 띄울 수 있는 버튼이 있음
  - 제품 뿐만 아니라, 아마존닷컴 전반적인 분야에 대해서 챗봇으로 탐색이 가능함
  - 유저가 키워드로 검색하는 수준을 넘어 내가 원하는 상품을 추천받을 수 있음.
    - e.g. 아이에게 줄 보드게임을 찾고 싶어

## What's next for 2025?

### Optimization
- 2024년은 프로덕션의 해. 서비스를 런칭하는 해였다.
- 이제는 런칭한 서비스를 최적화 할 때, 비용, 자원, AI 모델 등에 대한 최적화

#### Amazon Bedrock
- 완제품 형태의 AI서비스
- Amazon Nova
  - 최첨단 인텔리전스와 업계 최고의 가격 대비 성능을 제공하는 최첨단 Foundation 모델
- Bedrock 마켓플레이스
- 프롬프트 캐싱
- 프롬프트 라우팅
  - 질문의 수준에 맞춰서 AI 모델을 동적으로 선택하여 비용 절감
- 모델 Distillation

### Automation
- 사람의 손을 타지 않고, 스스로 생각하고 액션을 취할 수 있는 AI 에이전트
- 에이전트
  - 질문 -> AI 답변 -> AI 자체 재검토 -> 답변
- RAG
  - 검색 증강 생성
  - AI 모델은 학습을 하지 않음
  - 기업에서 사용하는 경우, 기업의 지식저장소(e.g. S3, DB 등) 제공
  - 질문 & 지식저장소 -> AI -> 답변
  - AI는 본인이 모르는 정보는 지식저장소를 경유해서 조회
- 프롬프트엔지니어링
  - 질문 -> AI -> 답변
  - AI에게 역할을 부여하고 그에 대해서 답변
- Text to SQL.. Redshift
