> 지식재산권 교육

## 지식재산권 개요
- Intellectual Property - 지식재산권
- IP팀, IPR팀 등으로 불림
- 지식재산권 = 지적재산권 = IPR(Intellectual Property Right) = IP

### 지식재산권 개요
- 지식재산권 > 산업재산권 / 지식재산처(특허청)
  - 특허권: 20년
  - 실용신안권: 10년
  - 디자인권: 20년
  - 상표권: 10년(갱신가능)
- 저작권 / 문체부
  - 저작권
    - 저작권자 사후 70년
    - 업무상 저작물은 공표일로부터 70년
- 소프트웨어의 경우 물건으로 취급이 어려워서 방법으로 취급 => 특허권으로 많이 사용함

- 특허권: 관련 장치, 방법 (e.g. 결제 방법, 앱기능, 배터리, 5G통신방법)
- 실용신안권: 관련장치
- 상표권: 제품의 식별표시
- 디자인권: 제품의 외관, 화면UI
- 저작권: SW 소스코드, 콘텐츠

## 특허
- 특허의 필요성
  - 자사 제품 보호
  - 경쟁사 저지
  - 특허 수익화
    - 특허 관련 소송으로 인한 배상금
    - 직무발명보상 제도: 관련 기술을 개발한 직원에게 보상
- 국내 특허법상 발명의 정의 (특허법 제2조 제 1호): 자연법칙을 이용한 기술적 사상의 창작으로 고도한 것
- 미국 법 기준: 태양 아래 인간이 만든 어떤 것이든 가능
- 회사에서 개발한 아이디어, 제품, 서비스, 애플리케이션, 솔루션 및 시스템 등은 대부분 특허의 대상이 됨

### AI 특허
- AI 특허 예시
  - 얼굴-당도 추정 시스템: 특허 불가. 얼굴과 과일의 당도는 연관이 없음
  - 자동운전차량: 특허 가능. 운전자의 모습으로부터 수동운전 모드 전환 가능 판단
    - e.g. 식사 중인 경우 수동운전모드 전환 불가
  - 사업 계획 지원 장치: 특하 가능.
- AI 특허 등록 요건: 신규성, 진보성
  - 특허 불가: 기존 기술에 단순히 AI를 더하기만 한 것
  - 특허 가능: 데이터 전처리 과정에 AI가 관여한 경우

## 저작권
- 소유권 & 저작권
- 소유권자
  - 물건(책, S/W CD)을 구입한 사람
  - 물건의 주인으로서 그 물건을 소유
  - 그 물건에 한해 이용 및 타인에게 양도(판매) 가능
  - 개인적인 목적으로만 복제 가능
  - 개인적인 목적으로 복제하고 그 복제물을 타인에게 양도(판매)하는 것은? => 불가
- 저작권자
  - 저작물(책 내용, S/W 소스코드)을 창작한 사람
  - 저작물에 대한 독점적 배타적인 이용권리 보유
  - 저작인격권: 공표권, 성명 표시권, 동일성유지권
  - 저작재산권: 복제권, 공연권, 공중송신권, 전시권, 배포권, 대여권, 2차적저작물작성권

### 저작권의 개념(소유권과 비교)
- 그림을 사면 구매자에게 그림의 저작권도 같이 넘어오는 것인가? > 그렇지 않음
- 구매자는 그림 전시회도 못하나? > 원본인 경우 가능, 다만 이것도 제약을 준수해야 가능함

### 저작권의 발생
- 저작권은 창작물을 창작한 때부터 발생하며 어떠한 절차나 형식의 이행을 필요로 하지 아니한다.
- 인터넷에 쉽게 복사되는 저작물(소스코드, 글, 사진, 이미지, 동영상, 캐릭터, 음악 등)은 그냥 사용해도 문제 없나?
  - 기본적으로는 유료 저작물이라 생각해야 함
  - 명시적으로 무료임이 표시된 것만 자유롭게 사용
  - 사용 조건(이용약관, 라이선스 등)을 확인

### 저작권 등록의 효과
- 등록한 사람을 저작자로, 창작연원일 또는 맨 처음의 공표연원일이 등록된 저작물은 등록된 연원일에 창작 또는 맨 처음 공표된 것으로 추정한다
- 저작권 등록은 안해도 되지만, 등록하면 나중에 소송할 때 편함
- 저작권 등록 사이트 - https://www.cros.or.kr

### 사진 저작권 사례
- 원숭이 나루토 셀카 사례 - 동물이 찍은 사진은 누구나 복제이용 가능
- AI 이미지 저작권 사례 - AI로 생성한 이미지는 누구나 복제이용 가능
  - 단, 현재 논란이 되고 있는 사항이므로 향후 변경될 가능성 존재
- 공공기관 홈페이지 이미지도 함부로 가져다 사용하면 안됨
- 폰트 프로그램 저작권 분쟁 사례 - 프로그램에 내장된 서체를 PDF로 저장해서 배포 > 폰트 저작권자에서 소송을 걸고 라이센스 계약을 요청함

### 구글 VS 오라클 저작권 분쟁 사례
- 타사 소프트웨어를 참고하여 자체 소프트웨어를 개발한 경우, 선언코드 부분만 복제하고 메인 소스코드는 복제하지 않았으면 문제가 없을까?
  - 10년의 소송 끝에 구글이 오라클에 승소
  - 소송 기간 동안 소비한 비용이 5천만불에 육박

### 소프트웨어 개발시 저작권 주의사항
- DB를 복제한 경우
- UI/UX를 거의 유사하게 만든 경우
- 리버스엔지니어링을 한 경우

### AI 학습 데이터 관련 사례
- AI 학습 데이터 수집 시, 불법 복제된 데이터 활용 금지
  - AI가 저작권 도서를 학습하는 행위는 지극히 변형적인(fairly transformative) 특성으로 공정 이용에 해당
  - 대량의 해적본을 저장하는 것은 저작권 침해로 결론

### 저작권 DO's VS Don't
- 사진 이미지는 라이선스 확인 후 사용
- 생성형 AI로 생성
- 직접 촬영한 사진
- 다른 이미지 참고하지 않고 그린 이미지
- 폰트 사용 시 라이선스

## 오픈소스
- 오픈소스 소프트웨어(OSS: Open Source Software)
- 저작권자(개발자)가 누구나 자유롭게 수정, 재배포할 수 있도록 소스코드를 공개한 소프트웨어
- 라이선스별로 이용 조건 존재
- 개발자들이 기작성된 오픈소스 소프트웨어 라이선스 계약서를 선택 적용
- 주요 오픈소스 라이선스 계약서들 중 하나를 선택하여 배포 시에 적용 필요

### 오픈소스 라이선스 위반 리스크
- 프랑스 법원, 대형 통신사 Orange에 Lasso 라이브러리 사용 관련하여 GPL 위반으로 손해배상 판결
- 계약위반(채무불이행), 저작권침해, 부정경쟁행위(성과물도용) 가능성 있음
- 돈 물어줘야 하나? -> 손해배상
- 앱 서비스 불가함? -> 침해금지 청구
- 벌금 or 감옥가나? -> 형사처벌

### 주요 오픈소스 라이선스
- AGPL
  - 리스크: 최상
  - 소스코드 공개의무: 웹서비스 시 및 배포시
  - 공개범위: 수정된 소스코드, 링크된 소스코드 공개
  - 예시: Grafana
- GPL
  - 리스크: 상
  - 소스코드 공개의무: 배포시
  - 공개범위: 수정된 소크소드, 링크된 소스코드
  - 예시: MySQL Community
- LGPL
  - 리스크: 중
  - 소스코드 공개의무: 배포시
  - 공개범위: 수정된 소스코드만 공개(링크된 범위)
  - 예시: JFreeChart
- EPL
  - 리스크: 중
  - 소스코드 공개의무: 배포시
  - 공개범위: 수정된 소스코드만 공개(모듈단위)
  - 예시: Eclipse
- MPL
  - 리스크: 중
  - 소스코드 공개의무: 배포시
  - 공개범위: 수정된 소스코드만 공개(파일단위)
  - 예시: Mozilla Firefox
- Apache
  - 리스크: 하
  - 소스코드 공개의무: 없음
  - 공개범위: 없음
  - 예시: Hadoop
- BSD
  - 리스크: 하
  - 소스코드 공개의무: 없음
  - 공개범위: 없음
  - 예시: Nginx
- MIT
  - 리스트: 하
  - 소스코드 공개의무: 없음
  - 공개범위: 없음
  - 예시: JQuery, Node.js

### 소스코드 공개의무 위반 사례
- 숨겨진 명작 게임 이코(ICO) - GPL 라이선스 위반으로 생산 종료
  - https://namu.wiki/w/%EC%9D%B4%EC%BD%94#s-7

### 소스코드 공개 의무 준수
- 불가피하게 소스코드 공개의무가 있는 라이선스(AGPL, GPL 등)의 오픈소스 사용시, 당사가 개발한 소프트웨어의 소스코드를 공개해야 함
  - 삼성 오픈소스

### 오픈소스 고지 의무 준수
- 오픈소스 고지문 게시: 앱 개발에 이용된 오픈소스 리스트 및 출처 표시
  - 오픈소스명, 링크, 저작권자, 적용 라이선스, 라이선스 전문 기재
